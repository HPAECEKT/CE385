1. รวมฟังก์ชันจัดการและสรุปข้อมูล (Functions)เป็นการใช้พวก Built-in Array Methods มาแปลงและสรุปข้อมูลนักศึกษาแบบไม่แก้ตัวแปรเดิม เช่น ใช้ .map() ดึงเฉพาะรายชื่อ, ใช้ .filter() คัดเฉพาะคนที่สอบผ่าน (50 คะแนนขึ้นไป), และใช้ .reduce() มาช่วยคิดทั้งคะแนนรวม, จัดกลุ่มนับจำนวนคนตามเกรด A-F ลง Object และวนหาตัวคนที่มีคะแนนสูงสุด (Top score)

2. การร้อยฟังก์ชันต่อกัน (Pipeline: Filter $\rightarrow$ Map $\rightarrow$ Reduce)
เป็นการเอา Method มาต่อ Chain กันเพื่อหาเกรดเฉลี่ยของเด็กภาค CE ที่สอบผ่าน โดยเริ่มจาก .filter() กรองเอาเฉพาะเด็ก CE ที่ได้คะแนนเกิน 50 ต่อด้วย .map() ดึงเอาเฉพาะตัวเลขคะแนนออกมา แล้วปิดด้วย .reduce() คำนวณหาค่าเฉลี่ยจบในรอบเดียว ได้คำตอบออกมาเป็น 76.5

3. การเทสกรณีข้อมูลว่าง (Edge Cases: [])
เป็นการลองส่ง Array ว่างเข้าไปทดสอบเพื่อเช็คว่าโปรแกรมจะแครชไหม ซึ่งผลคือผ่านทุกตัวเพราะเราใส่ Initial Value ให้กับ .reduce() ไว้หมดแล้ว (ได้ 0, {}, null ตามลำดับ) และในฟังก์ชันหาค่าเฉลี่ยก็มีการเช็คดัก students.length === 0 ไว้ก่อน ทำให้ไม่เจอปัญหาหารด้วยศูนย์หรือติดค่า NaN
