# Workshop 1 — พื้นฐาน JavaScript (CE385)

รายงานการปฏิบัติงานเขียนโปรแกรมภาษา JavaScript พื้นฐาน ประกอบด้วย 6 หัวข้อย่อย ดังนี้ครับ

1. ex1-profile.js (แนะนำตัว):** สร้างตัวแปรข้อมูลส่วนตัว แสดงผลด้วย Template Literal และคำนวณปีที่จะจบการศึกษา
2. ex2-types.js (ชนิดข้อมูลและ typeof):** ทดสอบการใช้ typeof กับชนิดข้อมูลต่างๆ, ค่า null กับ undefined และการแปลงชนิดข้อมูลด้วย Number()
3. ex3-calculator.js (เครื่องคิดเลขคะแนน):** คำนวณคะแนนรวมตามเกณฑ์รายวิชา พร้อมแปลงสัดส่วนคะแนน Workshop และคำนวณเปรียบเทียบเกณฑ์ด้วยตัวแปร const
4. ex4-grade.js (ตัดเกรดจากคะแนน):** เขียนฟังก์ชันแปลงเกรดด้วย if / else if พร้อมระบบตรวจสอบความถูกต้องของข้อมูล (Backend Validation) และทดสอบด้วย loop for...of
5. ex5-switch.js (ระบบสั่งอาหาร): คำนวณราคาร้านอาหารโดยใช้คำสั่ง switch...case ร่วมกับเทคนิค fall-through และการดักจับข้อผิดพลาดด้วย default
6. ex6-login.js (ระบบตรวจสอบสิทธิ์): จำลองระบบตรวจสอบสิทธิ์เข้าสู่ระบบด้วยตัวดำเนินการทางตรรกะ (`&&`, `||`, `===`) เรียงลำดับความปลอดภัยอย่างรัดกุม พร้อมคำตอบอธิบายเชิงวิศวกรรมซอฟต์แวร์ท้ายไฟล์
